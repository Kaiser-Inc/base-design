# KaiserInc Base documentation

[Português](../pt-BR/README.md)

Documentation for people who build KaiserInc products with the `@kaiserinc` registry, and for the agents that help them. It follows the [Diátaxis](https://diataxis.fr/) structure: pick the page by what you need right now.

| You want to | Read |
|---|---|
| Learn the system by building something | [Tutorial: your first screen](tutorial-first-screen.md) |
| Use the components in a project that already exists | [Install in an existing project](how-to/install-in-existing-project.md) |
| Add a new component to the registry | [Add a component](how-to/add-a-component.md) |
| Publish the registry | [Deploy the registry](how-to/deploy-the-registry.md) |
| Look up a component's variants, props and dependencies | [Components reference](reference/components.md) |
| Look up a token and where to use it | [Tokens reference](reference/tokens.md) |
| Understand why the system looks the way it does | [Design principles](explanation/design-principles.md) |
| Understand behaviors that break silently | [Known behaviors](explanation/known-behaviors.md) |

The showcase (`pnpm dev -p 3100` in this repository) shows every component in every state, with its install command and a code snippet.
