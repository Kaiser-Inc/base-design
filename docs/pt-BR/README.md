# Documentação do KaiserInc Base

[English](../en/README.md)

Documentação para quem constrói os produtos da KaiserInc com a registry `@kaiserinc`, e para os agentes que ajudam nisso. Ela segue a estrutura [Diátaxis](https://diataxis.fr/): escolha a página pelo que você precisa agora.

| Usar os componentes num projeto que já existe | [Instalar num projeto existente](how-to/install-in-existing-project.md) |
| Criar um componente novo na registry | [Criar um componente](how-to/add-a-component.md) |
| Publicar a registry | [Publicar a registry](how-to/deploy-the-registry.md) |
| Consultar variantes, props e dependências de um componente | [Referência de componentes](reference/components.md) |
| Consultar um token e onde usá-lo | [Referência de tokens](reference/tokens.md) |
| Entender por que o sistema tem essa cara | [Princípios de design](explanation/design-principles.md) |
| Entender comportamentos que quebram sem avisar | [Comportamentos conhecidos](explanation/known-behaviors.md) |

A vitrine (`pnpm dev -p 3100` neste repositório) mostra cada componente em todos os estados, com o comando de instalação e um trecho de código.
